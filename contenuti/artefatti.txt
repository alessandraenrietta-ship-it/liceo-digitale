# ===========================================================
#  L'ELENCO DEGLI ARTEFATTI
#
#  Ogni artefatto è un blocchetto di cinque righe: prima una riga
#  con tre trattini
#  ---
#  che serve a separarlo dal precedente, poi quattro righe con le
#  informazioni del lavoro.
#
#  Per aggiungerne uno: copia il modello che trovi in fondo,
#  incollalo sopra, togli il cancelletto dalle sue righe e
#  riempilo con i tuoi dati.
#
#  Che cosa scrivere in ogni riga:
#
#  TITOLO ....... il nome del lavoro, come lo leggeranno gli
#                 studenti sul sito
#  DISCIPLINA ... la materia (Storia, Matematica, Italiano...)
#  CARTELLA ..... il nome esatto della cartella che contiene il
#                 lavoro. Deve essere tutto minuscolo, con i
#                 trattini al posto degli spazi, senza accenti:
#                 per esempio  storia-la-rivoluzione-francese
#  DESCRIZIONE .. una o due righe che spiegano di che cosa si
#                 tratta
#
#  Attenzione: se la cartella scritta qui non esiste davvero,
#  cliccando sul titolo si aprirà una pagina di errore. Il nome
#  deve corrispondere in tutto, maiuscole comprese.
# ===========================================================
