#  COME SI LEGGE UNA RIGA

#    (sulla tastiera italiana: AltGr e il tasto del backslash)
#  - le righe vuote non danno fastidio

#  SE UNA RIGA È SCRITTA MALE non si blocca niente: la pagina
#  la salta e scrive in fondo quale riga ha saltato, così si

#  -----------------------------------------------------------
#  3. L'AULA DI OGNI CLASSE
#
#     AULA: classe | aula
#
#     È l'aula dove la classe sta normalmente. Serve perché
#     nell'orario l'aula si scrive solo quando la lezione si
#     sposta altrove (laboratorio, palestra): per tutte le
#     altre ore la pagina usa l'aula scritta qui.
#
#     Una classe senza la sua riga qui funziona lo stesso: al
#     posto dell'aula la pagina scrive "da definire".
#  -----------------------------------------------------------

AULA: 1A | A6
AULA: 2A | A7
AULA: 1B | A11


#  -----------------------------------------------------------
#  4. LE LEZIONI
#
#     LEZIONE: classe | giorno | ora | materia | insegnante | aula | compresenza
#
#     classe       come deve comparire sul sito (1A, 2B...)
#     giorno       uno dei giorni scritti al punto 2
#     ora          il numero dell'ora (1, 2, 3...)
#     materia      il nome della materia
#     insegnante   cognome e nome
#     aula         SI LASCIA VUOTO se la lezione si fa nell'aula
#                  della classe; si scrive solo quando si va da
#                  un'altra parte (palestra, L41_INFO...)
#     compresenza  il secondo insegnante, se c'è; altrimenti
#                  si lascia vuoto
#
#     Gli ultimi campi vuoti si possono anche non scrivere: una
#     riga che finisce dopo l'insegnante va benissimo.
#
#     PER AGGIUNGERE UNA LEZIONE si copia una riga esistente e
#     si cambiano i campi. PER TOGLIERNE UNA si cancella la
#     riga, oppure si mette un # davanti per metterla da parte
#     senza perderla.
#  -----------------------------------------------------------

#  5. LA SORVEGLIANZA DEGLI INTERVALLI
#
#     Durante l'intervallo l'insegnante dell'ora appena finita
#     resta a sorvegliare, e in certe aule deve fare cose
#     precise. Qui si scrive che cosa, aula per aula: chi guarda
#     il proprio orario se lo trova scritto nella casella
#     dell'ora giusta, senza doverselo ricordare.
#
#     Servono due cose.
#
#     SORVEGLIANZA ORE: le ore dopo le quali c'è l'intervallo,
#     separate dalla barra. Se la scansione oraria cambia, si
#     cambia questa riga e basta.
#
#     SORVEGLIANZA: aula | che cosa deve fare chi ci ha lezione
#     Una riga per aula. Il testo si legge così com'è scritto
#     qui: si può correggere liberamente. Un'aula senza riga,
#     o con il testo in bianco, non fa comparire niente.
#
#     C'è anche AVVISO ORA: ora | testo , per un avviso che
#     vale per tutti in una certa ora, qualunque sia l'aula.
#
#     ATTENZIONE: le righe qui sotto sono INVENTATE, come tutto
#     il resto di questo file. Le regole vere della scuola non
#     stanno nel sito, che è pubblico: stanno nel file che
#     ciascun docente carica dal proprio computer.
#  -----------------------------------------------------------
