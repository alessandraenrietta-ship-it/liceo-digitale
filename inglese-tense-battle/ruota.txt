# ============================================================
# TENSE BATTLE - LA RUOTA DELLE DOMANDE (SPEAKING WHEEL)
# ============================================================
#
# Questo file contiene le domande della ruota, la seconda parte
# del gioco, quella in cui le squadre parlano.
# Puoi modificarlo con un qualsiasi editor di testo (Blocco note
# va benissimo) e salvarlo: il sito cambia subito.
#
# COME È FATTO
# ------------
# Le domande sono divise per tempo verbale. Ogni gruppo comincia
# con la riga che contiene solo la parola TEMPO fra parentesi
# quadre, e poi contiene:
#
#   nome:          il nome del tempo verbale, come compare sul sito
#   colore:        il colore degli spicchi della ruota. Scrivi una
#                  di queste parole:
#                    blu, verde, blu scuro, ocra, viola, rosa
#   per iniziare:  i modi di cominciare la risposta, separati dal
#                  puntino ·
#   domanda:       una domanda della ruota. Scrivi una riga
#                  domanda: per ogni domanda che vuoi aggiungere
#
# Per aggiungere un tempo verbale nuovo, copia un gruppo intero
# qui sotto e cambiane il contenuto.
#
# ALTRE COSE DA SAPERE
# --------------------
# - Le righe che iniziano con # sono commenti: il sito le ignora.
# - Le righe vuote servono solo a rendere il file leggibile.
# - La ruota ha tanti spicchi quante sono le domande. Con più di
#   30 domande gli spicchi diventano molto stretti.
# - Se sbagli a scrivere un gruppo il sito non si blocca: lo
#   salta e, nella pagina delle squadre, ti dice quale rivedere.
#
# ============================================================
